# CLAUDE.md

Instructions for Claude in this repository, in every environment: Claude
Code locally, claude.ai code sessions, and any other Claude-powered agent.

- Follow `AGENTS.md` for layout rules, the contribution checklist, and the
  quality gates. Run `python3 scripts/validate-package.py` before every
  commit; it must pass.
- Never use the phrase "load-bearing" (in any spelling or hyphenation), in
  any output: docs, skill content, code comments, commit messages, PR
  bodies, or chat replies. Say what actually breaks instead: "installs
  depend on this", "renaming this breaks discovery". The prose lint
  enforces this for repo docs; this instruction extends it to everything
  Claude writes here.
- Repo prose is held to the writing bundle's own standard (see
  `skills/ai-writing-patterns/SKILL.md`): no em dashes, none of the
  catalog's flagship vocabulary, no filler.
